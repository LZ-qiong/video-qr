# 视频二维码项目

两段视频，各对应一枚二维码。**扫码即弹出全屏播放页并自动播放**。

## 在线地址

| 内容 | 网址 |
|---|---|
| 播放页导航 | https://lz-qiong.github.io/video-qr/ |
| 视频一 | https://lz-qiong.github.io/video-qr/v1/ |
| 视频二 | https://lz-qiong.github.io/video-qr/v2/ |

## 二维码

- `二维码-视频1.png`（1200×1200，扫描容错等级 H，指向 `/v1/`）
- `二维码-视频2.png`（1200×1200，扫描容错等级 H，指向 `/v2/`）
- `海报页.html` —— A4 可打印海报（二维码已内嵌，可独立打开/打印）

**二维码内容 = 上面的固定网址**，视频后续更新/替换都不需要重新生成二维码。

## 目录结构

```
├── index.html          播放页导航（两张卡片）
├── v1/index.html       视频一播放页（全屏、自动播放）
├── v2/index.html       视频二播放页
├── 二维码-视频1.png
├── 二维码-视频2.png
└── 海报页.html          可打印海报
```

## 播放页行为

1. 进入页面立即尝试**带声音自动播放**；
2. 若被浏览器策略拦截（iOS / 微信常见），自动降级为**静音自动播放**并显示"🔇 点击开启声音"按钮；
3. 若完全被拦截，显示**大播放按钮**，点击即播放；
4. 视频加载中显示缓冲提示；文件未上传时显示"视频即将上线"。
